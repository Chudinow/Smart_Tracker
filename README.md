# Work Life Balance

Веб-приложение для трекинга привычек и настроения: отмечай выполнение (чекбоксы и счётчики), смотри ленту по дням в календаре и аналитику за 7/30/90 дней (включая график настроения).

---

## Возможности

- ✅ Регистрация и вход пользователя (сессии)
- ✅ Привычки:
  - **checkbox** (выполнено/не выполнено)
  - **counter** (например, “вода 0/3”)
- ✅ Главная страница “Мой день” — список привычек на сегодня, логирование выполнения
- ✅ “Лента” (календарь) — обзор месяца:
  - прогрессбар = % выполнения за день
  - иконки: настроение / заметка / предупреждение о пропусках
  - просмотр выбранного дня справа
- ✅ “Аналитика”:
  - вкладки Stats / Habits / Mood
  - SVG-график настроения (с разрывами, тултипы по точкам)
  - сводные KPI за период

## Как это работает (в двух словах)

- Роуты в `app/ui/main.py` отрисовывают страницы через `Jinja2Templates`.
- Данные и вычисления берутся из `app/db/repo.py`.
- База описана моделями SQLAlchemy в `app/db/models.py`.
- Страницы — это HTML-шаблоны (Jinja), поэтому “фронт” по сути генерируется сервером.
- Прогрессбар и иконки в календаре — **это не JS**, это результат бэкенд-расчётов, прокинутых в шаблон.

---

## Асинхронность: где она тут и зачем

FastAPI запускается на ASGI-сервере (обычно `uvicorn`) и внутри использует `asyncio` для обслуживания запросов.

При этом:
- даже если у тебя много “обычных” (`def`) обработчиков — сервер всё равно работает в async-окружении;
- сейчас работа с БД через SQLAlchemy Session (sync), поэтому запросы выполняются синхронно (обычный подход для MVP).

То, что ты видишь в трассировках `asyncio.run(...)` — это внутренняя “машина” uvicorn/ASGI, а не обязательно твой код.

## Установка и запуск (локально)

### 1) Требования
Рекомендую Python **3.11 / 3.12**.

> На Python 3.13 у некоторых версий SQLAlchemy могут быть странные ошибки типизации. Если видишь ошибки уровня `TypingOnly` — почти всегда лечится переходом на 3.12 или обновлением зависимостей.

### 2) Виртуальное окружение
**Windows (PowerShell)**
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
Проект сделан в стиле “тонкие роуты + репозиторий + шаблоны”.

macOS/Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
```
### 3) Установка зависимостей
```bash
pip install -r requirements.txt
```
### 4) Запуск сервера
```bash
uvicorn app.ui.main:app --reload --port 8000
```
Открывай:
http://127.0.0.1:8000/ или http://127.0.0.1:8000/app

## Календарь в “Ленте”: как считаются проценты и иконки

Ключевая функция: get_month_overview(...) в app/db/repo.py.

Идея расчёта:
Берём активные привычки пользователя (их число = total_habits)
По логам за день считаем прогресс каждой привычки:
counter: min(value/target, 1.0)
checkbox: 1 или 0

Для дня суммируем прогрессы и переводим в проценты:
percent = int((sum_progress / total_habits) * 100)

Плюс подтягиваем MoodEntry и определяем:
mood_score → emoji
has_note → 📝
warn → ⚠ если есть данные, но выполнено < 100%

Дальше шаблон history.html просто рисует:
прогрессбар через style="--p: {{ cell.percent }}%"
иконки через условия Jinja

## Частые проблемы

1) VS Code подчёркивает Jinja как CSS-ошибки
Это не баг кода, а линтер VS Code, который думает, что {{ ... }} — это CSS/HTML мусор.
Решение:
поставь расширение для Jinja (например, Better Jinja)
либо отключи конкретные проверки для html-шаблонов

2) Два виртуальных окружения
Оставь одно: .venv/.
В VS Code выбери интерпретатор:
Ctrl+Shift+P → Python: Select Interpreter → .venv

4) SQLAlchemy ломается на Python 3.13
Либо:
переход на Python 3.12,
либо:
обновление зависимостей до совместимых версий.
